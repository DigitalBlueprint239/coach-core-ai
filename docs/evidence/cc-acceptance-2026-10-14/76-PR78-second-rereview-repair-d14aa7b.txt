2. Design decision (details: docs/security/RELEASE_PROOF_IMPORT_OFF_2026-10-18.md §Design rationale)
   Rejected: real-browser UI drive of the release bundle (needs faked Firebase Auth/Firestore; component renders only when signed in with a team);
   whole-module execution with webpack's runtime (app module mounts on evaluation; component not exported). Chosen: a STATIC, environment-independent
   OFF contract — the bound function's first statement must be an unconditional `throw new <Ctor>(<msg>)` with <msg> the disabled literal or a const
   bound to it, and <Ctor> neither declared in scope nor assigned/redefined (globalThis/self/window/Object.defineProperty/Reflect.set) anywhere in the
   chunk. Such a function cannot reach a backend whatever its arguments, closures or global state; nothing is reconstructed or synthesised for OFF.
   Handler binding now accounts for EVERY direct call (setters/props allowed; member-expression callees, unresolved callees, second handlers, extra
   awaits => inconclusive). ON is proved only by execution with an immutable closure (pure builtins, module-scope functions, immutable-literal consts,
   none reassigned/mutated — scope-aware, so minified name reuse no longer confuses it) and counts backend reads, copies and storage writes.
