2. Root cause (design doc §"Why the verifier repeatedly accepted…"): every revision tried to decide a semantic property of arbitrary compiled
   JavaScript ("no backend effect reachable from this handler") with a syntactic whitelist; each review supplied an evaluation point the model
   lacked (setter arguments React invokes, valueOf, accessors, explicit global receivers, aliased Reflect, tampered module loader, enclosing
   finally, duplicate JSX keys) and each exemption added for the real bundle widened the accepted language. The ON control synthesised arguments
   and predicates to execute outside a browser, so it could report ON where the real UI never enables. Both legs modelled the engine instead of
   using it. Decision: retire all output-level behaviour claims; keep only decidable legs and a real-execution leg.
