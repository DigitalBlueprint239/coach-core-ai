# ADR-005 — Five knowledge categories; Verified bar unchanged
Status: Proposed (bar wording RD-01). Date: 2026-11-03.
Decision: Verified / Expert-reviewed / Coach-authored / Provisional AI / Insufficient evidence, with a source registry tracking rights and independence groups. Expert review never counts as sources. Coaches' private plays need no citations.
Consequences: T-105 extends today's Verification type; UI labels everywhere content appears.
