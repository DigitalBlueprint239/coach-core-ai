# ADR-007 — Simulation fidelity tiers and honest labelling
Status: Proposed. Date: 2026-11-03.
Decision: Tier A assignment playback ('teaching animation'), Tier B rule-based reactions ('rule-based simulation'), Tier C advanced tactical ('exploratory simulation'). No outcome probabilities or expected yards without a validated, calibrated model and data.
Consequences: UI and docs must label the tier wherever animation is shown.
