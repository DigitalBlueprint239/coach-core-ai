# ADR-004 — Deterministic rules decide; AI drafts and explains
Status: **Accepted** — tightened by owner decisions 2 and 3 (2026-11-03). Date: 2026-11-03.
Owner decisions: AI responds **only** to explicit coach requests (no popups, no unsolicited panels, no background calls on edits) and **never modifies plays** (no AI write operations, auto-corrections or one-click rewrites at this stage). Deterministic validation warnings are not AI.
Implemented contract: `src/football-core/advisory.ts` (`requestAdvice`: coach-action trigger required, deep-frozen context, response limited to status/statements/suggestions, provider failure → 'unavailable'; `createDisabledAdvisor`: deterministic facts when AI is off).
Decision: legality, eligibility, slot mapping, conflicts and coverage responsibilities are deterministic football-core rules with tests. AI runs server-side only (one gateway with OpenAI/Anthropic adapters per the owner's 2026-10-13 decision; Smart Playbook provider = RD-10) and returns **explanations and text suggestions only** (no structured drafts that write), citing registry sources; every statement is labelled deterministic-fact / verified-knowledge / coach-provided / assumption / interpretation / unknown. No invented tendencies; no unsupported probabilities. Live AI stays off until owners enable it.
Consequences: AI work starts after model v3 (T-103) and registry (T-105).
